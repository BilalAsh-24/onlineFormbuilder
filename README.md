# Dynamic Form Builder Backend

## Overview
Backend API service for the Dynamic Form Builder & Response Management System built using Node.js, Express.js, and database integration for handling authentication, forms, and responses.

## Features
- User Authentication
- RESTful API Architecture
- Dynamic Form Management
- CRUD Operations
- Response Storage & Retrieval
- Database Integration
- Secure Backend Configuration

## Technologies Used
- Node.js
- Express.js
- MongoDB / MySQL
- JWT Authentication
- Sequelize / Mongoose

## API Functionalities
- User Login & Signup
- Create Forms
- Edit & Delete Forms
- Submit Responses
- Fetch Form Responses
- Manage User Data
